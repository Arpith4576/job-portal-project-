#  Job Portal

### A Modern Full-Stack Job Recruitment Platform

*Connecting Job Seekers with Employers Efficiently*

---

##  Overview

The Job Portal is a full-stack web application developed using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). The platform provides a centralized system where job seekers can search and apply for jobs, while employers can post vacancies and manage applications.

The project aims to simplify the recruitment process by offering a user-friendly interface, secure authentication, job management tools, and application tracking features.

---

## Features

### Job Seeker Features

* User Registration & Login
* Create and Manage Profile
* Browse Available Jobs
* Search and Filter Jobs
* Apply for Jobs Online
* Upload Resume
* Save Favorite Jobs
* Track Application Status
* View Applied Jobs History

### Employer Features

* Employer Registration & Login
* Company Profile Management
* Post New Job Openings
* Edit or Delete Job Posts
* Manage Applications
* View Candidate Profiles
* Update Application Status
* Dashboard Analytics

### Security Features

* JWT Authentication
* Password Encryption using Bcrypt
* Role-Based Access Control
* Protected Routes
* Secure API Endpoints

1. User Registers/Login.
2. Job Seeker Searches Available Jobs.
3. Job Seeker Applies for Desired Job.
4. Employer Reviews Applications.
5. Employer Updates Application Status.
6. Candidate Tracks Application Progress.

## ⚙️ Installation Guide

### Clone Repository

```bash
git clone https://github.com/yourusername/job-portal.git
cd job-portal
```

### Backend Setup

```bash
cd backend
npm install
npm run dev
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

## Environment Variables

Create a `.env` file inside the backend folder:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
```
